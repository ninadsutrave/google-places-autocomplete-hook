# Security

## Supported versions

Security fixes go into the latest release.

## Reporting a vulnerability

Please don't open a public issue. Use [private vulnerability reporting](https://github.com/ninadsutrave/google-places-autocomplete-hook/security/advisories/new) on GitHub, or email ninadsutrave@gmail.com.

You'll get a reply within a few days. Once a fix is released, the advisory is published with credit to you unless you'd rather stay anonymous.

This package runs in the browser and only talks to Google's Maps JavaScript API. Don't put your Maps API key anywhere it isn't meant to be public, and restrict it to your domains in Google Cloud.
